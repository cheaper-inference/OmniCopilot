## Settings

| Setting | Used for |
| --- | --- |
| `chat.utilityModel` | Titles, summaries and commit messages. |
| `chat.utilitySmallModel` | The small, fast tasks. |
| `inlineChat.defaultModel` | Inline chat in the editor. |

Each one takes a model from the picker.

These settings exist in recent versions of VS Code; on an older one the search comes back empty.
